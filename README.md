# EcommerceStore
 Функционал
Для пользователей:
 Регистрация и авторизация (JWT + bcrypt)
️ Просмотр каталога товаров с фильтрацией и поиском
 Добавление товаров в корзину и избранное
Оформление заказа с указанием адреса доставки
Личный кабинет с историей заказов
 Оставление отзывов и оценок товаров
 
🛠 Стек технологий
Frontend
React 18 — UI-библиотека с компонентным подходом
TypeScript — строгая типизация
Vite — быстрая сборка проекта
React Router DOM — маршрутизация
Axios — HTTP-клиент с перехватчиками
Context API — управление состоянием (Auth, Cart, Wishlist)
CSS Modules — изолированные стили
React Hot Toast — уведомления
Backend
Node.js — среда выполнения
Express.js — веб-фреймворк
TypeScript — типизация серверной части
PostgreSQL — реляционная база данных
Drizzle ORM — типобезопасная работа с БД
JWT — аутентификация и авторизация
bcrypt — хеширование паролей
